隱私權政策

沒劇本工作室  ·  最後更新：2025 年

一、應用程式用途

本應用程式（「白露」）專為沒劇本工作室之 Facebook 粉絲專頁自動化管理而設計， 功能包含自動發文、讀取貼文留言及回覆互動，僅限粉絲專頁管理員本人使用。

本應用程式不對一般公眾開放使用，亦不提供任何登入或授權入口供第三方存取。

二、資料收集

本應用程式不收集、儲存或處理任何使用者個人資料。

所有 Facebook API 操作均透過 Meta 官方 Graph API 進行，遵守 Meta 平台政策， 僅存取粉絲專頁管理所必要之資訊（貼文內容、留言），不涉及任何個人識別資料。

三、資料使用

透過 Facebook Graph API 取得之資料，僅用於粉絲專頁內容管理目的， 包含自動回覆留言及定時發文排程，不會用於廣告、分析或任何商業目的。

四、資料分享

本應用程式不會將任何資料分享、出售或轉移給第三方。

五、資料刪除

如需刪除與本應用程式相關之任何資料，請透過下方聯絡方式與我們聯繫， 我們將於 30 日內完成處理。

您也可以直接至 Facebook 設定中撤銷本應用程式的授權。

六、聯絡方式

如有任何隱私權相關問題，請透過 Facebook 粉絲專頁私訊聯絡沒劇本工作室。
